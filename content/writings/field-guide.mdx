## Code

```sql title="dual-write.sql" {3-4}
-- Write to both stores until the backfill catches up
begin;
insert into posts (id, title) values ($1, $2);
insert into posts_v2 (id, title, created_at) values ($1, $2, now());
commit;
```

<CodeGroup>

```ts title="worker.ts"
export async function run(batch: number) {
	const rows = await db.select().from(posts).limit(batch);
	return rows.length;
}
```

```bash title="deploy.sh"
docker compose up -d --build
```

</CodeGroup>

## Steps

<Steps>
	<Step title="Add the new column">Nullable, with no default, so the change is instant.</Step>
	<Step title="Backfill in batches">A thousand rows at a time, with a pause between.</Step>
	<Step title="Switch the reads">Behind a flag, so it can go back in a second.</Step>
</Steps>

## Questions

<AccordionGroup>
	<Accordion title="Why not do it in one migration?">Because one migration holds the lock for the whole table.</Accordion>
	<Accordion title="How long did the backfill take?">About four hours, spread over two nights.</Accordion>
